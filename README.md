
# Andelsblik

Andelsblik er en Expo-prototype til andelsboligforeninger. Appen samler beskeder fra administrationen og viceværten og gør det nemt at finde kontaktoplysninger på godkendte håndværkere.

## Demovideo

Demovideoen kan tilgås via dette YouTube link: 
https://youtube.com/shorts/d1QOysTC8g4?feature=share

## Funktioner

- `Opslagstavle`: beboere kan læse opslag, og administrationen kan oprette nye opslag.
- `Håndværkere`: søg i fagpersoner og tilføj navn, fagområde, telefonnummer og e-mail.
- Data gemmes lokalt med AsyncStorage, så nye opslag og fagpersoner huskes efter genstart på den samme enhed.

## Opsætning

```bash
cd obliOpg2
npm install
npx expo start
```
